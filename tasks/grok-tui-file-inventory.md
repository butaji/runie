# Grok TUI file inventory

The authoritative Grok source inventory is generated by
`scripts/source-inventory.sh`, which scans both:

- `crates/codegen/xai-grok-pager/src`
- `crates/codegen/xai-grok-pager-render/src`

The script intentionally emits paths rather than a hand-maintained copy, so
new Grok components cannot silently bypass the parity review. For each file,
the review must classify it as one of:

- mapped to a Pi-core event/state and implemented in Runie;
- renderer-only infrastructure represented by a pure model/paint contract;
- Grok-only behavior explicitly excluded by the p30 scope.

Run the scan from the Runie repository with:

```sh
scripts/source-inventory.sh > /tmp/runie-source-inventory.tsv
```

The file is evidence for source coverage, not a claim that every Grok feature
belongs in Runie. Runie remains limited to Pi-core capabilities while matching
Grok’s visual reach for those capabilities.
