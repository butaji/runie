# Assistant message

## Contract

Markdown is parsed into styled spans while the logical message remains plain
event-owned text. Wrapping reserves timestamp width on the first content row.

## Variants

Headings, emphasis, links, inline/fenced code, blockquotes, bullets, tables,
multiline output, and completed-message rail normalization.

## Acceptance

`visual-markdown-rich.yaml` plus cell-style assertions cover every variant.
